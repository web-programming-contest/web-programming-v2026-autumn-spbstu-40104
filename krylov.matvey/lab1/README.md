# Лабораторная работа 1

## Задание

Вариант №7 Создать три карточки товара. Каждая карточка должна быть представлена
div-блоком, содержащим:

- Изображение (размер 200px на 150px);
- Заголовок (шрифт Arial, размер 18px, жирный стиль);
- Описание (шрифт Arial, размер 14px). Карточки должны располагаться в одну
  строку (горизонтально) с отступом 20px между ними. Для всех элементов
  используйте padding: 10px.

## Реализация

Были созданы три карточки товара с изображениями, взятыми со всем известного
маркетплейса, заголовком и описанием. Все стили вынесены в отдельный CSS-файл.
Селекторы намеренно постарался сделать вложенными, чтобы разграничить стили для
конкретных объектов, хотя пока в этом не было практической нужды. Расположение
карточек по горизонтали реализовал через атрибут display: flex

## Запуск

Откройте `index.html` в браузере.
