# Лабораторная работа 3

## Задание

Вариант 7 Реализуйте функцию difference(arr1, arr2), которая возвращает массив
элементов, которых нет во втором массиве

## Реализация

Экспортируемая функция принимает на вход 2 массива любой длины и возвращает
массив, состоящий из элементов, отсутствующих во втором массиве. Алгоритм
использует цикл по элементам первого массива и метод includes(), проверяющий
наличие соответствующего элемента во втором массиве. Метод includes() корректно
обрабатывает случаи, когда массив для поиска пустой, и возвращает false. Если
оба массива пусты, то функция вернет пустой массив. Если все элементы массива 1
есть в массиве 2, то функция так же вернет пустой массив

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
