# Лабораторная работа 2

## Задание

Вариант 7 Написать функцию findLongestPalindrome(str), которая находит и
возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

Экспортируемая функция принимает на вход один параметр - строку и возвращает
самый длинный палиндром, являющийся подстрокой входной строки. В качестве
алгоритма был выбран полный перебор всех символьных последовательностей входной
строки. Для пустой строки функция вернет пустую строку, для строки без
палиндромов (1 символ) функция вернет 1 символ. При нахождении нескольких
палиндромов максимальной длины во входной строке функция вернет первый найденный

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
