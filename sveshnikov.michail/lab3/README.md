# Лабораторная работа 3

## Задание

Вариант 38

Реализуйте функцию sortByFrequency(arr), которая сортирует элементы массива по
частоте встречаемости.

| Функция           | Описание                                                            |
| ----------------- | ------------------------------------------------------------------- |
| `sortByFrequency` | Частые элементы идут первыми; случаи равной частоты не проверяются. |

## Реализация

Сначала функция находит уникальные значения в списке и для каждого подсчитывает
количество вхождений. Элементы складываются в `Map`, чтобы обеспечить наиболее
быстрый их поиск для увеличения счётчика вхождений. Затем мапа преобразуется в
массив пар `[элемент, количество вхождений]` и сортируется по убыванию значений
количества вхождений. После создаётся новый массив, в который записывается
каждый элемент по очереди ровно столько раз, сколько раз он встречался в
исходном массиве.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.

```javascript
import {sortByFrequency} from './solution.js';
```
