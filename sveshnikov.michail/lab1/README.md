# Лабораторная работа 1

## Задание

Вариант 38

Создать «хлебные крошки» как на изображении ниже. «Хлебные крошки» должны
удовлетворять следующим требованиям:

- Основа структуры – список;
- Элементы списка – ссылки;
- Последний элемент списка – span;
- Цвет ссылок - #0056ff;
- Ссылка при наведении подчеркивается снизу;
- Цвет span-элемента - #333;
- Стрелки между элементами реализованы через псевдо-элемент after.

## Реализация

- Основа структуры - тег `<nav>` с классом `.bread-crumbs`, внутри которого
  находится тег `<ul>` со свойствами `display: flex` и `flex-wrap: wrap`, чтобы
  текст не вылезал за пределы страницы, а переносился. Чтобы список был в одну
  строку, сбросил значения по умолчанию для свойств `list-style`, `padding`,
  `margin`;
- Элементы списка - `<li>`, первые два являются ссылками - тег `<a>`;
- Последний элемент списка – вместо `<a>` использовал `<span>`;
- Для ссылок класс `.address` и свойство `color: #0056ff`;
- Для подчёркивания снизу при наведении использовался псевдокласс `:hover` и
  свойство `text-decoration`;
- Цвет для последнего элемента списка задан с помощью отдельного класса CSS и
  свойства `color: #333`;
- Стрелки между элементами реализованы через псевдоэлемент `::after` для тега
  `<li>` с псевдоклассом `:not(:last-child)`, чтобы после последнего элемента в
  списке не стояла стрелочка, и свойств `content` и `margin`.

## Запуск

Откройте `index.html` в браузере.
