# Лабораторная работа 2

## Задание

Вариант 38

Сделайте функцию, которая параметром будет получать дату, а
возвращать знак зодиака, соответствующий этой дате.

| Функция | Описание |
|---------|----------|
| `getZodiacSign` | Принимает `Date`, возвращает русское название знака с заглавной буквы. |

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
