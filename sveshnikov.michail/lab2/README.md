# Лабораторная работа 2

## Задание

Вариант 38

Сделайте функцию, которая параметром будет получать дату, а возвращать знак
зодиака, соответствующий этой дате.

| Функция         | Описание                                                               |
| --------------- | ---------------------------------------------------------------------- |
| `getZodiacSign` | Принимает `Date`, возвращает русское название знака с заглавной буквы. |

## Реализация

Имеется таблица с данными по каждому знаку зодиака. Дата задаётся входным
параметром. Из неё достаётся месяц и число, а дальше в цикле `for` перебираются
знаки зодиака и в `if` проверяется, входит ли дата в диапазон дат этого знака.
Проверка вхождения в диапазон проводится по двум отрезкам, которые разделены по
признаку различия в месяце: то есть, если лев с 23.07 по 23.08, то проверяться
будет вхождение в отрезки [23.07, 31.07] и [1.08, 23.08]. Если да, то возвращаем
название этого знака.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.

```javascript
import {getZodiacSign} from './solution.js';
```
