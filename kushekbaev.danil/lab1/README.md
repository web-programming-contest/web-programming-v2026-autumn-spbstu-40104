# Lab1 — Форма регистрации

Учебный проект: форма регистрации на HTML + CSS.

## Структура
- `index.html` — разметка формы
- `styles.css` — стили (внешний файл, inline styles отсутствуют)

## Реализовано
- Поля: имя, фамилия (text)
- Пол — радиокнопки (одиночный выбор)
- Владение языками — чекбоксы (множественный выбор)
- Макет на CSS Grid: лейблы слева, поля справа
- Состояния `:hover` и `:focus` / `:focus-visible`
- Адаптивность: на узких экранах (< 480px) — одна колонка

## Запуск
Открыть `index.html` в браузере.
