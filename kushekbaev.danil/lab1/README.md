# Лабораторная работа 1

## Задание

Создать форму регистрации с полями ввода (Имя, Фамилия), выбором пола
(радиокнопки) и выбором языков (чекбоксы). Форма должна быть визуально разделена
на две половины: лейблы слева, поля ввода справа.

## Реализация

Семантическая форма с подключённым внешним styles.css. Макет формы построен на
CSS Grid: две колонки — узкая для лейблов (слева) и широкая для полей ввода
(справа). Для выбора пола используются радиокнопки (`type="radio"`),
обеспечивающие одиночный выбор, а для языков — чекбоксы (`type="checkbox"`),
позволяющие выбрать несколько вариантов. Добавлены состояния hover и
focus-visible, а также адаптивность: на экранах уже 480px сетка перестраивается
в одну колонку. Все стили вынесены в styles.css, inline styles отсутствуют.

## Запуск

Открыть файл index.html в браузере через двойной клик. Дополнительная сборка не
требуется.
