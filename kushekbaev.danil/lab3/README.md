# Лабораторная работа 2 (или 3)

## Задание

Реализовать функцию `findMedian(arr)`, которая вычисляет медиану числового
массива.

## Реализация

Функция создает копию исходного массива с помощью spread-оператора, чтобы не
мутировать исходные данные. Затем копия сортируется по возрастанию (с
использованием числового компаратора). Если длина массива нечетная, возвращается
центральный элемент. Если четная — среднее арифметическое двух центральных
элементов.

## Запуск

Файл `solution.js` является ES-модулем. Экспортирует функцию `findMedian`. Для
запуска требуется среда с поддержкой ES-модулей (Node.js 14+ с
`"type": "module"` или браузер).
