# Лабораторная работа 2

## Задание

Написать функцию `findMissingNumber(arr)`, находящую пропущенное число в массиве целых чисел от 1 до N (одно пропущено).

## Реализация

Функция использует математическую формулу суммы арифметической прогрессии (формула Гаусса). Вычисляется ожидаемая сумма чисел от 1 до N, из неё вычитается фактическая сумма элементов массива. Разница является пропущенным числом. Сложность алгоритма — O(n) по времени и O(1) по памяти.

## Запуск

Файл `solution.js` является ES-модулем. Экспортирует функцию `findMissingNumber`. Для запуска требуется среда с поддержкой ES-модулей (Node.js 14+ с `"type": "module"` или браузер).
