# Лабораторная работа 2

## Задание

Вариант 9

Создать функцию `isBalanced(str)`, проверяющую сбалансированность скобок
`()[]{}` в строке (например: `"{[()]}"` -> true, `"[(])"` -> false).

## Реализация

Экспортируемая функция проверяет строку на сбалансированность пробелов. Основной
алгоритм работы функции:

- Цикл по символам строки:
  - Если символ равен одной из открывающих скобок, то он помещатся в конец
    рабочего массива;
  - Если символ равен одной из закрывающих скобок, то:
    - Если последний символ в рабочем массиве, т. е. последняя найденная
      открывающая скобка, не соответствует найденной закрывающей, функция
      возвращает false;
    - Иначе, последняя найденная открывающая скобка удаляется из рабочего
      массива;
- После цикла оценивается состояние рабочего массива:
  - Если в массиве остались элементы, т. е. найденные открывающие скобки, то
    функция возвращает false;
  - Иначе - true.

## Запуск

- Импортируйте именованный export из `solution.js` как ES module;
- Запустите локально с помощью Node.js: `node solution.js`.
