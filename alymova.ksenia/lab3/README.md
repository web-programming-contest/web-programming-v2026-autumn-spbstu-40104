# Лабораторная работа 3

## Задание

Вариант 9

Реализуйте функцию `findPairsWithSum(arr, sum)`, которая возвращает все пары
чисел, дающие в сумме `sum`.

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

Экспортируемая функция возвращает все уникальные пары чисел, содержащихся в
переданном массиве, дающих в сумме переданное значение. Основной алгоритм работы
функции:

- Копирование исходного массива и сортировка копии по убывания;
- Цикл по всем элементам копии:
  - Вложенный цикл по всем последующим элементам копии:
    - Если элемент с индексом внешнего цикла в сумме с элементом с индексом
      вложенного массива равны `sum`:
      - Если результирующий массив уже не содержит такую пару, то она
        добавляется в результат;
      - Иначе - пара пропускается;
    - Если элемент с индексом внешнего цикла в сумме с элементом с индексом
      вложенного массиве больше `sum`:
      - Вложенный цикл прерывается, из-за сортировки массива все последующие
        пары тоже будут больше `sum`;
- Возвращается результирующий массив с найденными парами.

## Запуск

- Импортируйте именованный export из `solution.js` как ES module;
- Запустите локально с помощью Node.js: `node solution.js`.
