# Лабораторная работа 3

## Задание

Реализовать функцию `findPairsWithSum(arr, sum)`, которая возвращает все пары
чисел, дающие в сумме `sum`.

## Реализация

Решение находится в `solution.js` и экспортирует именованную функцию
`findPairsWithSum`. Функция перебирает все пары элементов с разными индексами
`i < j`. Если `arr[i] + arr[j] === sum`, пара `[arr[i], arr[j]]` добавляется в
результат. Пары возвращаются в порядке появления элементов в массиве,
повторяющиеся числа образуют отдельные пары. Исходный массив не изменяется, для
пустого массива или массива из одного элемента возвращается пустой массив. Если
`arr` не является массивом, выбрасывается `TypeError`. Сложность по времени -
O(n²), по памяти - O(k), где k - количество найденных пар.

## Запуск

Функцию можно импортировать как ES-модуль и вызвать из консоли Node.js:

```js
import {findPairsWithSum} from './solution.js';

console.log(findPairsWithSum([1, 2, 3, 4, 5], 6)); // [[1, 5], [2, 4]]
```
