Лабораторная работа 1 Задание

Создать каталог товаров, сгруппированных по категориям. Категории и товары
представлены в виде вложенных списков. Внутри каждой категории находится список
товаров. Каждый товар содержит название, выделенное жирным шрифтом, краткое
описание и цену, выделенную курсивом.

Реализация

Страница состоит из index.html и styles.css. Каталог - это список ul, каждая
категория - элемент li с вложенным списком ul товаров. Название товара размечено
тегом strong, цена - тегом em, описание - абзацем p. Оформление вынесено в
styles.css, inline-стилей и ID-селекторов нет. Страница адаптивна: ширина
контента ограничена, горизонтального скролла нет.

Запуск

Откройте файл index.html в браузере или запустите расширение Live Server в VS
Code.
