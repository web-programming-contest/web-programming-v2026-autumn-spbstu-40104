# Лабораторная работа 2

## Задание

Создать функцию `isBalanced(str)`, проверяющую сбалансированность скобок
`()[]{}` в строке. Например, `"{[()]}"` → `true`, `"[(])"` → `false`.

## Реализация

Решение находится в `solution.js` и экспортирует именованную функцию
`isBalanced`. Строка обходится один раз слева направо, для проверки используется
стек. Открывающая скобка кладётся в стек. Для закрывающей скобки из стека
извлекается последняя открывающая, и они должны быть парой. Если пары нет или
стек пуст, функция сразу возвращает `false`. В конце стек должен быть пуст.
Символы, не являющиеся скобками, игнорируются, пустая строка считается
сбалансированной. Сложность по времени и памяти — O(n).

## Запуск

Функцию можно импортировать как ES-модуль и вызвать из консоли Node.js:

```js
import {isBalanced} from './solution.js';

console.log(isBalanced('{[()]}')); // true
console.log(isBalanced('[(])')); // false
```
