# Лабораторная работа 4

## Задание

Вариант 27: класс `Student` и коллекции студентов.

### 4.1. Класс `Student`

Поля:

- `id` — уникальный идентификатор (число);
- `name` — имя студента (строка);
- `grades` — объект, где ключи — названия предметов, а значения — оценки
  (числа).

Методы:

- `addGrade(subject, grade)` — добавляет или обновляет оценку по предмету;
- `removeGrade(subject)` — удаляет оценку по предмету;
- `getAverageGrade()` — возвращает средний балл по всем предметам;
- геттер `summary` — возвращает строку
  `"Студент [name] (id: [id]) — средний балл: [средний балл]"`.

### 4.2. Функции коллекций

- `groupStudentsByAverageGrade(students)` — группирует студентов по среднему
  баллу; возвращает `Map` средний балл → массив студентов.
- `getUniqueSubjects(students)` — возвращает уникальный список всех предметов,
  встречающихся у студентов.
- `groupStudentsBySubject(students)` — группирует студентов по предметам,
  возвращая `Map` предмет → массив студентов, у которых есть оценка.
- `getTopStudents(students)` — возвращает массив студентов с максимальным
  средним баллом.
- `findStudentsBySubject(students, subject, minGrade = 3)` — возвращает список
  студентов, сдавших указанный предмет (оценка не ниже `minGrade`).

### 4.3. Интерфейс

- Список карточек студентов с ID, именем, средним баллом и списком предметов с
  оценками.
- Форма добавления студента (поля `id`, `name`).
- В каждой карточке форма оценки: предмет (ввод или выбор из списка уже
  существующих предметов) и оценка (выбор 5–2), кнопки «Добавить оценку» и
  «Удалить оценку».
- Кнопка удаления студента внутри карточки.
- Все операции добавления и удаления выполняются асинхронно через `Promise` +
  `setTimeout`.
- Список автоматически перерисовывается после каждой операции.
- Текущий список студентов сохраняется в `localStorage` и восстанавливается при
  следующем открытии страницы.

## Реализация

Класс `Student` хранит оценки в объекте `grades`. `addGrade` записывает оценку
по ключу-предмету (новый ключ добавляется, существующий перезаписывается),
`removeGrade` удаляет ключ через `delete`.

`getAverageGrade` получает массив оценок через `Object.values`, проверяет длину
(при отсутствии оценок возвращает 0) и считает сумму циклом `for...of`. Геттер
`summary` формирует строку по шаблону, средний балл округляется до двух знаков
через `toFixed(2)`.

Функции коллекций:

- `getUniqueSubjects` — перебор `grades` циклом `for...in`, предмет добавляется,
  только если его ещё нет в массиве (`includes`);
- `groupStudentsByAverageGrade` — `Map` с методами `has/get/set`, ключ — средний
  балл;
- `groupStudentsBySubject` — `Map`, для каждого предмета из `getUniqueSubjects`
  через `filter` и оператор `in` отбираются студенты, у которых есть оценка по
  нему;
- `getTopStudents` — поиск максимума через `Math.max` в цикле и `filter` для
  отбора всех, у кого средний балл равен максимуму;
- `findStudentsBySubject` — `filter` по условию `grades[subject] >= minGrade`.

Интерфейс (`main.js`): все изменения проходят через функцию `change` — действие
выполняется в `setTimeout` внутри `Promise`, затем список сохраняется в
`localStorage` и карточки перерисовываются. Кнопки и формы карточек
обрабатываются одним обработчиком на списке; студент находится по `data-id`
карточки. При добавлении проверяется уникальность ID. Если `localStorage` пуст,
загружаются три студента-примера.
