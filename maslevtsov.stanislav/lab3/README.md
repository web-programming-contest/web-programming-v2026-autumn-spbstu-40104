# Лабораторная работа 3

## Задание

Вариант 24

Реализуйте функцию maxSlidingWindow(arr, k), которая находит максимумы во всех
подмассивах длины k.

## Реализация

Если в функцию не передан массив или он пустой, то она возвращает пустой массив.
Затем в цикле по длине массива выполняются четыре действия:

- Если первый элемент в очереди индексов массива меньше левой границы, то он
  удаляется;
- Элементы массива, индексы которых находятся в очереди, меньшие или равные
  текущему элементу массива удаляются;
- Индекс текущего элемента массива добавляется в очередь;
- Элемент массива под первым в очереди индексом (т. е. максимальный) добавляется
  в результирующий массив если уже обработано как минимум k элементов массива.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
