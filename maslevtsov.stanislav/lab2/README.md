# Лабораторная работа 2

## Задание

Вариант 24

Реализуйте функцию zipArrays(...arrays), которая объединяет массивы
поэлементно (например, zipArrays([1, 2], ['a', 'b']) → [[1, 'a'], [2, 'b']]).

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
