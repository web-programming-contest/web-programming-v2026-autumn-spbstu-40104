# Лабораторная работа 1

## Задание

Вариант 24

Создать регистрационную форму (<form>) со следующими полями ввода:

- Имя (текстовое поле);
- Фамилия (текстовое поле);
- Email (текстовое поле);
- Пароль (текстовое поле);
- Подтверждение пароля (текстовое поле);
- Дата рождения (поле выбора даты);
- Страна (выпадающий список <select> с type="text" для каждого option);
- Согласие с условием (checkbox);
- Кнопка отправки. Фон кнопки — зеленый (#008000), цвет текста — белый.

В полях ввода необходимо корректно использовать атрибут type. Используйте
отступы между полями в 20px, цвет фона формы — белый, цвет текста — черный.

## Реализация

Страница состоит из формы с полями имя, фамилия, email, пароль, подтверждение
пароля, дата рождения, страна, checkbox и кнопки отправки.

Для изменения цвета текста и фона и выравнивания в теге form установлен атрибут
class со значением "registration-form".

Для отступов между полями все поля кроме последнего (кнопка отправки) разделены
тегом div с атрибутом class со значением "form-field".

Для изменения цвета текста и фона кнопки отправки в теге button установлен
атрибут class со значением "submit-button".

Для изменения отступов между полями использовано свойство margin-bottom, для
изменения цвета текста и фона - color и background-color соответственно.

## Запуск

Откройте `index.html` в браузере.
