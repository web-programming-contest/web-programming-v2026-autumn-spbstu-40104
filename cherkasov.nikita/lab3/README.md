# Лабораторная работа 3

## Задание

Вариант 21. Реализовать функцию `findMaxSubarraySum(arr, n)`, которая находит
максимальную сумму подмассива длины `n` в массиве `arr`.

## Реализация

Используется метод скользящего окна за один проход по массиву. Сначала
вычисляется сумма первых `n` элементов — это стартовое значение окна и текущий
максимум. Далее окно последовательно сдвигается на один элемент вправо: к сумме
прибавляется новый элемент, выходящий в окно, и вычитается элемент, покидающий
окно слева. После каждого сдвига сумма сравнивается с текущим максимумом. Такой
подход даёт сложность `O(arr.length)` вместо `O(arr.length * n)` при пересчёте
суммы окна с нуля на каждом шаге. Отрицательные суммы допускаются, исходный
массив `arr` не изменяется.

## Запуск

Функция экспортируется как ES module из `solution.js`:

```js
node -e "import('./solution.js').then(m => console.log(m.findMaxSubarraySum([1,-2,3,4,-1,2], 3)))"
```

Ожидаемый результат: 6
