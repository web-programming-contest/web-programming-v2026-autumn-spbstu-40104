# Лабораторная работа 2

## Задание

Вариант 21. Написать функцию, которая генерирует все простые числа до заданного
числа `n` (решето Эратосфена). Функция экспортируется под именем
`generatePrimes` и возвращает простые числа `<= n` по возрастанию.

## Реализация

Используется классическое решето Эратосфена: булев массив `isComposite` размером
`n + 1` отмечает составные числа. Для каждого ещё не помеченного числа `i`,
начиная с 2, все его кратные, начиная с `i * i`, помечаются как составные. В
конце собираются все индексы, оставшиеся непомеченными — это и есть простые
числа. Для `n < 2` возвращается пустой массив. Функция является чистой (не
изменяет входные данные) и синхронной — возвращает результат напрямую, без
Promise.

## Запуск

Запустить проверку локально можно через Node.js:

```
node --experimental-vm-modules -e "import('./solution.js').then(m => console.log(m.generatePrimes(30)))"
```
