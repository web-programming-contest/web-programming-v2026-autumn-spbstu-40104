# Лабораторная работа 2

## Задание

Вариант 25

Написать функцию findLongestPalindrome(str), которая находит и возвращает самую
длинную подстроку-палиндром в переданной строке.

## Реализация

Как настоящий плюсовик я сразу же принялся думать как можно сделать функцию
`findLongestPalindrome(str)` наиболее эффективной (хотя то, что получилось еще
не предел), поэтому сейчас алгоритм работает так:

- Генерирует исключение `TypeError`, если `str` не `string`
- Сразу возвращает `str`, если ее длина меньше двух
- Идет по строке и ищет подстроки типа `aa` или `aba`. Если находит - пускает в
  обе стороны индексы и читает палиндром, при этом следит за границами строки и
  возвращает максимальный по длине палиндром
- Если не находит палиндромов (даже `aa`), возвращает пустую строку

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
