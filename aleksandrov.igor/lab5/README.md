# Лабораторная работа 5

## Задание

Вариант 6.

Создать компонент Timer, который позволяет установить время в минутах и
запускает обратный отсчет с визуальным отображением оставшегося времени.

Структура компонента:

- функциональный компонент с использованием React хуков (`useState`,
  `useEffect`)
- поле ввода для установки количества минут (целое число)
- кнопка "Запуск" для начала отсчета
- отображение таймера в формате MM:SS
- запуск по нажатию кнопки или по нажатию клавиши Enter в инпуте
- обратный отсчет с обновлением каждую секунду
- при завершении отсчета показ сообщения "Готово" через alert или модальное
  окно. Сброс таймера.

## Реализация

- main.jsx - компонент `Timer` и точка входа
- styles.css - стили
- состояние хранится в `useState`, обратный отсчет реализован через
  `useEffect` + `setTimeout`

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
