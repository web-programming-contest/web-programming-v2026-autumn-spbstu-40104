# Лабораторная работа 1

## Задание

Вариант 39. Создать форму регистрации как на предложенном изображении. Форма
должна удовлетворять следующим требованиям:

- Ширина формы – 400px;
- Внутренний отступ – 8px;
- Цвет кнопки - #0056ff;
- Цвет кнопки при наведении курсора - #417ffb.

## Реализация

HTML-форма регистрации с полями для имени, электронной почты, телефона и
двукратного ввода пароля. С помощью CSS заданы ширина формы 400px, отступы,
белый фон и светло-серая рамка. Поля ввода и кнопка занимают всю ширину формы.
Для кнопки установлен синий фон, белый текст и изменение цвета при наведении
курсора.

## Запуск

Откройте `index.html` в браузере.
