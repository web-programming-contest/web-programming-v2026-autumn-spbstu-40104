# Лабораторная работа 3

## Задание

Вариант 39.  Реализуйте функцию countOccurrences(arr), которая возвращает
объект с количеством вхождений каждого элемента

## Реализация

Для подсчёта используется перебор массива с помощью цикла for...of. Каждый элемент преобразуется в строку с помощью String(), которая используется в качестве ключа объекта. Если ключ уже существует, его значение увеличивается на единицу. Если ключ встречается впервые, он добавляется в объект со значением 1.

Граничные случаи:
 при передаче пустого массива функция возвращает пустой объект {}. Если массив содержит только один элемент, для него создаётся счётчик со значением 1. При наличии повторяющихся элементов их количество корректно подсчитывается. Если элементы разных типов имеют одинаковое строковое представление, они учитываются под одним ключом объекта.
