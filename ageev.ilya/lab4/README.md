# Лабораторная работа 4

## Задание

Вариант 4. Реализовать класс заказа, пять функций для обработки массива заказов
и интерфейс управления заказами и товарами с асинхронным добавлением и
удалением.

## Реализация

В `model.js` находятся класс `Order` и пять именованных функций обработки
коллекции. `main.js` создаёт карточки заказов, обрабатывает формы, обновляет DOM
и сохраняет состояние в localStorage. Добавление и удаление выполняются через
Promise с задержкой setTimeout. После загрузки сохранённые заказы
восстанавливаются как экземпляры класса. Статусы имеют строковые значения `new`,
`processing`, `completed`, `cancelled`; в интерфейсе показаны русские названия.
Демонстрационные заказы используются при первом запуске. Уникальность товаров
определяется по названию. Границы сумм: до 1000 включительно, свыше 1000 до 5000
включительно и свыше 5000.

## Запуск

Открыть папку репозитория в VS Code и запустить `index.html` через расширение
Live Server. Для ES-модулей требуется локальный HTTP-сервер, а не открытие файла
через file://. В интерфейсе можно добавить заказ, изменить статус, добавить или
удалить товары, проверить пять операций анализа и обновить страницу для проверки
восстановления заказов.
