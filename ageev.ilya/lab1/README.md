# Лабораторная работа 1

## Задание

Вариант 4. Создать таблицу продаж из трёх столбцов и пяти строк данных.
Отобразить итоговое количество товаров и выручку, чередовать цвета строк и
выделять строку при наведении курсора.

## Реализация

В `index.html` таблица разделена на `thead`, `tbody` и `tfoot`. В `styles.css`
чередование фона реализовано псевдоклассом `:nth-child`, выделение строки —
псевдоклассом `:hover`. Для примера выбраны пять видов товаров; общие значения
составляют 100 единиц и 1 795 000 рублей.

## Запуск

Открыть файл `index.html` в браузере или запустить страницу через Live Server в
VS Code. Навести курсор на строки таблицы для проверки выделения.
