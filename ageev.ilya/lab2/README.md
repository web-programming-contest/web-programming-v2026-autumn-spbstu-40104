# Лабораторная работа 2

## Задание

Вариант 4. Реализовать функцию convertBase(num, fromBase, toBase), преобразующую
число между системами счисления.

## Реализация

Для преобразования числа в десятичную систему используется функция parseInt. Для
перевода в целевую систему счисления применяется метод toString. Функция
экспортируется из модуля solution.js.

## Запуск

Для проверки решения необходимо импортировать функцию convertBase из файла
solution.js и вызвать её с нужными аргументами в Node.js.
