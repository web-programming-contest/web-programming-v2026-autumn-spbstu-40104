# Лабораторная работа 3

## Задание

Вариант 4. Реализовать функцию mergeArrays(arr1, arr2), которая объединяет два
массива, удаляя дубликаты.

## Реализация

Для объединения массивов используется оператор spread. Повторяющиеся значения
удаляются с помощью коллекции Set. Полученная коллекция преобразуется обратно в
массив. Исходные массивы не изменяются.

## Запуск

Для проверки решения необходимо импортировать функцию mergeArrays из файла
solution.js и вызвать её с двумя массивами в Node.js.
