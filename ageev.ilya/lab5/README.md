# Лабораторная работа 5

## Задание

Вариант 4. Реализовать книжный интернет-магазин с обложками, названиями,
описаниями, ценами и рейтингом книг. Пользователь может поставить оценку. Через
3–4 секунды после голосования отображается среднее значение оценок.

## Реализация

Приложение написано на React и собирается с помощью Vite. В `src/books.js`
хранятся демонстрационные данные и функция вычисления среднего арифметического.
Компонент `BookCard` отвечает за карточку книги и хранит пользовательскую
оценку. Повторное голосование заменяет предыдущую оценку этого пользователя.
Компонент `Rating` принимает рейтинг, обработчик голосования и количество звёзд
(по умолчанию пять). С помощью `useState` он временно отображает выбранное
значение, а через 3500 мс возвращается к обновлённому среднему рейтингу. Таймер
очищается при повторном голосовании и размонтировании компонента. Обложки
находятся в локальном каталоге `assets/`.

## Запуск

В каталоге лабораторной выполнить:

```bash
npm install
npm run dev
```

Открыть локальный адрес, показанный Vite. Для сборки выполнить `npm run build`.
