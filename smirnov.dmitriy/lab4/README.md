# Лабораторная работа 4

## Задание

Разработать приложение для управления мероприятиями.

Приложение должно поддерживать создание и удаление мероприятий, добавление и
удаление участников, поиск и группировку данных.

## Реализация

Создан класс Event со свойствами ID, название, участники и дата.

Реализованы методы добавления и удаления участников.

Добавлены функции группировки мероприятий по дате и количеству участников,
получения уникальных участников и поиска мероприятий по участнику или месяцу.

Для интерфейса используется JavaScript и DOM API.

Асинхронные операции выполняются через Promise и setTimeout.

Данные сохраняются в localStorage.

## Запуск

Открой файл index.html через локальный сервер.

Например, выполни в терминале:

```bash
python3 -m http.server 8000
```

Затем открой http://localhost:8000/smirnov.dmitriy/lab4/
