# Лабораторная работа 3

## Задание

Вариант №32. Реализовать функцию `difference(arr1, arr2)`, которая возвращает
массив элементов, которых нет во втором массиве.

## Реализация

Решение находится в файле `solution.js` и экспортирует именованную функцию
`difference`. Алгоритм состоит из трёх шагов:

1. Вспомогательная функция `buildLookup` помещает элементы второго массива в
   `Set`. Проверка наличия элемента в `Set` выполняется за O(1), поэтому не
   нужно для каждого элемента первого массива просматривать весь второй массив.
2. Основная функция проходит по первому массиву циклом `for...of`.
3. Если элемента нет в множестве, он добавляется в новый массив `result`.

Общая сложность составляет O(n + m), где n и m — длины массивов. Порядок
элементов первого массива сохраняется, повторы в нём тоже. Исходные массивы не
изменяются, так как результат собирается в новом массиве. `Set` корректно
работает со значением `NaN`. Если один из аргументов не является массивом,
функция выбрасывает `TypeError`. Пустой первый массив даёт пустой результат,
пустой второй массив даёт копию первого. Функция синхронная и возвращает
результат, а не выводит его в консоль.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {difference} from './solution.js';

console.log(difference([1, 2, 3, 4], [2, 4])); // [1, 3]
```
