# Лабораторная работа 2

## Задание

Вариант №32. Написать функцию `findLongestPalindrome(str)`, которая находит и
возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

Решение находится в файле `solution.js` и экспортирует именованную функцию
`findLongestPalindrome`. Используется метод расширения от центра: каждая позиция
строки проверяется как центр палиндрома нечётной длины (центр — один символ) и
чётной длины (центр — между двумя соседними символами). От центра границы
расширяются в обе стороны, пока символы совпадают. Вспомогательная функция
`expandAroundCenter` возвращает границы найденного палиндрома, а основная
функция запоминает самые длинные из них. Сложность — O(n²) по времени и O(1) по
дополнительной памяти.

Граничные случаи: пустая строка возвращает пустую строку, строка из одного
символа возвращает этот символ, строка без палиндромов длиннее одного символа
возвращает первый символ. Если есть несколько палиндромов одинаковой длины,
возвращается тот, который встречается первым. Функция синхронная и возвращает
результат, а не выводит его в консоль.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {findLongestPalindrome} from './solution.js';

console.log(findLongestPalindrome('forgeeksskeegfor'));
```
