# Лабораторная работа 1

## Задание

Вариант №32. Сверстать флаг Японии. Красный круг в центре сделать с помощью
`position: absolute`, разместив его точно по центру так, чтобы он оставался по
центру даже при изменении размеров флага. Размеры флага выбираются
самостоятельно.

## Реализация

Флаг — это блок `.flag` с `position: relative`, белым фоном и пропорциями 3:2
(`aspect-ratio`). Внутри лежит блок `.flag-circle` с `position: absolute`. Центр
задан через `inset: 0` и `margin: auto`, поэтому круг остаётся по центру при
любом размере флага. Размер круга указан в процентах от ширины флага (40%), а
форма кругом получена через `aspect-ratio: 1` и `border-radius: 50%`. Ширина
флага ограничена `min(450px, 100%)`, поэтому на узких экранах нет
горизонтального скролла.

## Запуск

Откройте `index.html` в браузере.
