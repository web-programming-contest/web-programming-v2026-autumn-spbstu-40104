# Лабораторная работа 1

## Задание

Вариант 30. Создать форму регистрации с полями ввода имени и фамилии, выбором
пола и возможностью выбора нескольких языков. Форма должна быть разделена на две
колонки: слева — подписи, справа — поля ввода.

## Реализация

В файле `index.html` создана форма регистрации. Для ввода имени и фамилии
используется `type="text"`, для выбора пола — `type="radio"`, для выбора языков
— `type="checkbox"`.

В файле `styles.css` реализовано оформление формы. Для разделения формы на две
колонки используется Grid, для расположения вариантов выбора — Flexbox. Для
адаптации под небольшие экраны используется медиазапрос. Кнопка регистрации
меняет цвет при наведении курсора.

## Запуск

Открыть файл `index.html` в браузере.
