# Лабораторная работа 2

## Задание

Вариант 30. Написать функцию `toBinary(num)`, преобразующую неотрицательное
целое десятичное число в двоичную строку без ведущих нулей. Для числа 0 функция
должна возвращать строку `"0"`.

## Реализация

Решение реализовано на JavaScript в файле `solution.js`.

Для перевода числа в двоичную систему используется последовательное деление
на 2. На каждой итерации остаток от деления добавляется в начало результирующей
строки, а число делится на 2 с округлением вниз. Цикл продолжается до тех пор,
пока число не станет равным нулю.

Случай с числом 0 обрабатывается отдельно.

Функция `toBinary` имеет именованный экспорт.

## Запуск

Из корневой папки репозитория выполнить команду:

```bash
node --input-type=module -e "import {toBinary} from './voronina.nadia/lab2/solution.js'; console.log(toBinary(13));"
```

Результат выполнения: `1101`.
