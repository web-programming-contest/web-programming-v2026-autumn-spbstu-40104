# Лабораторная работа 1

## Задание

Вариант 18.

Создать карточку товара с изображением, названием и ценой. При наведении фон
карточки становится светло-голубым (`#e0f7fa`), появляется чёрная тень со
смещением 5 px по обеим осям, размытием 10 px и прозрачностью 20%, а изображение
увеличивается на 10%. Все изменения происходят одновременно.

## Реализация

Карточка размечена в `index.html`, оформление и эффекты наведения находятся в
`styles.css`. Фон, тень и масштаб изображения меняются с одинаковой
длительностью перехода. Изображение хранится локально в `assets/headphones.svg`.
Для пользователей, предпочитающих меньше анимации, переходы отключены.

## Запуск

Откройте `index.html` в браузере и наведите курсор на карточку.
