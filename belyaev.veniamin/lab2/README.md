# Лабораторная работа 2

## Задание

Вариант 18.

Написать функцию, которая проверяет, является ли строка панграммой, то есть
содержит ли она все буквы алфавита.

Контракт варианта: именованный export `isPangram` из `solution.js`; проверяется
английский алфавит `a`–`z`, регистр игнорируется.

## Реализация

Функция `isPangram(text)` работает в один проход по строке:

1. строка приводится к нижнему регистру, поэтому регистр не важен;
2. символы собираются во множество `Set`, но добавляются только латинские буквы
   `a`–`z` — пробелы, цифры, пунктуация и буквы других алфавитов пропускаются;
3. строка считается панграммой, если в множестве оказалось ровно 26 уникальных
   букв (`ALPHABET_SIZE`).

Граничные случаи:

- пустая строка и строка без латинских букв — не панграмма;
- каждая буква встречается ровно один раз — панграмма;
- регистр и лишние символы не мешают:
  `THE QUICK BROWN FOX, JUMPS OVER THE LAZY DOG!` — панграмма;
- буквы других алфавитов (`é`, `я`) не учитываются как латинские.
