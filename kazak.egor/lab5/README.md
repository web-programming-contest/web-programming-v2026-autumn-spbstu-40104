# Лабораторная работа 5

## Задание

Вариант 28. React-приложение с деревом книг: автор → издательство → жанр →
книга. Ветки раскрываются и сворачиваются.

## Реализация

src/books.js содержит исходные локальные данные. В src/main.jsx используются
React-компоненты App, TreeLevel и TreeBranch. TreeLevel рекурсивно строит четыре
уровня, TreeBranch хранит состояние раскрытия через useState. Ветки изначально
раскрыты; кнопки поддерживают click, Enter и пробел. Сворачивание родителя
скрывает потомков и сохраняет состояние вложенных веток. Компоненты описаны
через JSX. Стили находятся в src/styles.css. Добавлены app, tree, tree-toggle,
tree-branch и tree-level для проверок курса. Во время работы приложение не
обращается к внешним ресурсам.

## Запуск

Перейдите в каталог лабораторной:

```bash
cd kazak.egor/lab5
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Для сборки выполните npm run build, для
просмотра сборки — npx vite preview. node_modules, dist и lock-файл не
загружайте в репозиторий.
