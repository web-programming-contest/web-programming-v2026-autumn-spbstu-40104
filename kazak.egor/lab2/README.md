# Лабораторная работа 2

## Задание

Вариант 28. Вычислить арифметическое выражение с приоритетом умножения перед
сложением, например: 2 + 3 * 4 = 14.

## Реализация

`solution.js` именованно экспортирует `calculateExpression(expr)`.

Функция принимает корректную непустую строку с числами и операциями `+` и `*`.
Метод `split('+')` выделяет слагаемые, а `split('*')` — множители внутри каждого
слагаемого. Вложенные циклы `for...of` сначала находят произведения, затем
складывают их. `Number` преобразует строки в числа; пробелы вокруг чисел
допускаются.

Использованы темы лекций: преобразование типов из лекции 4, циклы `for...of`,
вложенные циклы, `split` и функции из лекции 5. Регулярные выражения, `eval` и
дополнительный разбор вычитания и деления не используются. Проверка
некорректного ввода и поддержка скобок в задание не входят.

Именованный `export` сохранён по обязательному требованию курса для lab2 и lab3.

## Запуск

Из корня репозитория выполните команду Node.js:

```bash
node --input-type=module -e "import {calculateExpression} from './kazak.egor/lab2/solution.js'; console.log(calculateExpression('2 + 3 * 4'));"
```

Ожидаемый результат: 14.
