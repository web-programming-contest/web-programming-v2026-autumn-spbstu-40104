# Лабораторная работа 2

## Задание

Вариант 28. Вычислить арифметическое выражение с приоритетом умножения перед
сложением, например: 2 + 3 * 4 = 14.

## Реализация

solution.js именованно экспортирует calculateExpression(expr). Исходный алгоритм
читает числа и операторы слева направо, сначала вычисляя произведения и частные.
Сохранена поддержка вычитания, деления, десятичных чисел и знака числа. Скобки
не поддерживаются. Пустой ввод, неверное выражение и деление на ноль вызывают
Error. eval не используется.

## Запуск

Из корня репозитория выполните команду Node.js:

```bash
node --input-type=module -e "import {calculateExpression} from './kazak.egor/lab2/solution.js'; console.log(calculateExpression('2 + 3 * 4'));"
```

Ожидаемый результат: 14.
