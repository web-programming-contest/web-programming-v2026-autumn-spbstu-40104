# Лабораторная работа 1

## Задание

Вариант 28. Макет страницы: заголовок, боковая панель шириной 300px, основная
область и футер. Каждая область имеет свой фон и чёрную рамку 1px. Использовать
Grid или Flexbox.

## Реализация

В index.html используются header, aside, main и footer. В styles.css задан Grid
с двумя колонками. На узком экране области располагаются в одну колонку, чтобы
избежать горизонтальной прокрутки. Боковая панель сохраняет ширину 300px при
наличии места.

## Запуск

Откройте index.html в браузере. Дополнительные зависимости не нужны.
