# Лабораторная работа 3

## Задание

Вариант 28. Найти наиболее часто встречающийся элемент массива чисел или строк.

## Реализация

solution.js именованно экспортирует findMostFrequent(arr). Map хранит число
вхождений каждого элемента, затем выбирается максимальная частота. Входной
массив не изменяется. При равных частотах остаётся первый встретившийся элемент;
для пустого массива возвращается undefined.

## Запуск

Из корня репозитория выполните команду Node.js:

```bash
node --input-type=module -e "import {findMostFrequent} from './kazak.egor/lab3/solution.js'; console.log(findMostFrequent([1, 2, 2, 3]));"
```

Ожидаемый результат: 2.
