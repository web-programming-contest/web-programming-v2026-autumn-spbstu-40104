# Лабораторная работа 4

## Задание

Вариант 28. Каталог фильмов и актёров. Реализовать класс Movie, добавление и
удаление актёров, getter castSize и пять функций обработки коллекции. Создание и
удаление фильмов через интерфейс должны быть асинхронными, с сохранением в
localStorage.

## Реализация

model.js экспортирует Movie, groupMoviesByDirector, getUniqueActors,
groupMoviesByCastSize, findMoviesByActor и getMovieTitles. Группировки
возвращают Map, остальные функции — массивы. Функции не меняют входную
коллекцию. main.js отвечает за DOM, формы и localStorage. Изменения выполняются
через Promise и setTimeout с задержкой 300 мс. После загрузки из JSON фильмы
снова создаются как экземпляры Movie. Повторный актёр не добавляется. Поля
title/director и data-testid соответствуют публичному контракту курса.

## Запуск

Нужен локальный HTTP-сервер, поскольку main.js импортирует ES module. Например,
из корня репозитория:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/kazak.egor/lab4/. Добавьте фильм и актёра,
перезагрузите страницу, затем удалите их и проверьте сохранение изменений. Для
просмотра модели импортируйте model.js как ES module.
